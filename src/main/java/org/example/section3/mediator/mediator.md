## 중재자(Mediator) 패턴
- 여러 객체들이 소통하는 방법을 캡슐화하는 패턴
- 여러 컴포넌트간의 결합도를 중재자를 통해 낮출 수 있음 


### 장단점
- 장점
  - 컴포넌트 코드를 변경하지 않고 새로운 중재자를 만들어 사용할 수 있음
  - 각각의 컴포넌트 코드를 보다 간결하게 유지할 수 있음
- 단점
  - 중재자 역할을 하는 클래스의 복잡도와 결합도가 증가함 


### 실무에서는 어떻게 쓰이나?
- 자바 -> 둘다 일종의 중재자패턴으로 볼 수는 있으나 대표적인 예시로 보긴 힘듬
  - ExecutorService 
  - Executor
- 스프링
  - DispatcherServlet : HandlerAdapter, HandlerMapping 등 서로 연관이 없는 컴포넌트들을 전부 가지고 있는 중재자역할의 클래스
