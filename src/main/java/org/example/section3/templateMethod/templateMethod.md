## 템플릿 메서드(Template Method) 패턴
- 알고리즘 구조를 서브 클래스가 확장할 수 있도록 템플릿으로 제공하는 방법
- 추상 클래스는 템플릿을 제공하고 하위 클래스는 구체적인 알고리즘을 제공함 


### 장단점
- 장점
  - 템플릿 코드를 재사용하고 중복 코드를 줄일 수 있음
  - 템플릿 코드를 변경하지 않고 상속을 받아서 구체적인 알고리즘만 변경할 수 있음
- 단점
  - 리스코프 치환 원칙을 위반할 수도 있음
  - 알고리즘 구조가 복잡할 수록 템플릿을 유지하기 어려워짐 


### 실무에서는 어떻게 쓰이나?
- 자바
  - HttpServlet 이 대표적인 예시 
- 스프링
  - WebSecurityConfigurerAdapter 의 configure 메서드를 통해 구체적인 알고리즘을 재정의하게 됨 



### 템플릿 콜백(Template-Callback) 패턴
- 템플릿 메서드, 전략 패턴과 유사하지만 다른 패턴
- 콜백으로 상속 대신 위임을 사용하는 템플릿 패턴
- 상속 대신 익명 내부 클래스 또는 람다 표현식을 활용할 수 있음
