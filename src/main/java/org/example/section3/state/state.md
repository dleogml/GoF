## 상태(State) 패턴
- 객체 내부 상태 변경에 따라 객체의 행동이 달라지는 패턴
- 상태에 특화된 행동들을 분리해 낼 수 있으며, 새로운 행동을 추가하더라도 다른 행동에 영향을 주지 않음


### 장단점
- 장점
  - 상태에 따른 동작을 개별 클래스로 옮겨서 관리할 수 있음(가장 큰 장점)
  - 기존의 특정 상태에 따른 동작을 변경하지 않고 새로운 상태에 다른 동작을 추가할 수 있음
  - 코드 복잡도를 줄일 수 있음
- 단점
  - 복잡도가 증가함 


### 실무에서는 어떻게 쓰이나? 
- 자바와 스프링에서는 찾기가 힘듬
- 보통 비즈니스 로직과 관련해서 적용되어 있는 경우가 많음
